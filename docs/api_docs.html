news-scraper API

Documentazione specifica per l'integrazione n8n e scraping news

Panoramica

Il microservizio espone endpoint REST per l'estrazione di notizie tramite Playwright. È ottimizzato per restituire testo pulito pronto per l'elaborazione da parte di modelli LLM.

Endpoints

GET /health

Verifica lo stato di salute del servizio.

Risposta:

{
  "status": "ok"
}

POST /scrape

Scansiona una pagina indice (es. Diablo Immortal News) ed estrae le ultime N notizie.

Body (JSON):

Campo Tipo Default Descrizione
url String diabloimmortal.blizzard.com... URL della pagina news da scansionare.
max_articles Integer 1 Numero massimo di articoli da estrarre e processare.

Esempio richiesta:

{
  "max_articles": 3
}

Risposta (Array di oggetti):

[
  {
    "title": "Titolo Notizia",
    "url": "https://news.blizzard.com/...",
    "published_date": "10 giugno 2026",
    "content": "Testo estratto dell'articolo...",
    "thumbnail_url": "https://..."
  }
]

POST /scrape/article

Estrae i dati da un singolo URL specifico di un articolo.

Query Parameters:

Parametro Tipo Obbligatorio Descrizione
url String Sì URL completo dell'articolo da scrapare.

Risposta:

Restituisce un singolo oggetto articolo (stessa struttura della lista sopra).

Dettagli Tecnici

  • Smart Scraping: Il servizio non utilizza fragili selettori CSS/Regex. Converte la pagina in Markdown tramite MarkItDown di Microsoft e delega l'identificazione strutturale dei link all'LLM (OpenAI API compatibile).
  • Universalità dei Link: Include un motore di pre-processing che normalizza i Custom Web Components con attributi href (es. <blz-button>) in tag <a> standard e risolve gli URL relativi in assoluti prima della conversione.
  • Formato Data: Le date ISO vengono convertite in formato testuale italiano (es. "10 giugno 2026") o estratte direttamente dall'LLM se non reperibili nei metadati.
  • Limiti Contenuto: Il campo content è limitato a 8000 caratteri per evitare overflow nei prompt LLM di n8n.
  • Tecnologia: Basato su Playwright (Chromium) per gestire contenuti caricati dinamicamente via JavaScript, integrato con l'auto-installazione del browser all'avvio.

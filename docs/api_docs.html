news-scraper API

Documentazione specifica per l'integrazione n8n e scraping news

Panoramica

Il microservizio espone endpoint REST per l'estrazione di notizie tramite Playwright. È ottimizzato per restituire testo pulito pronto per l'elaborazione da parte di modelli LLM.

Autenticazione: Se configurata nel file .env tramite API_AUTH_TOKEN, tutti gli endpoint di scraping (esclusa la rotta di health check) richiedono l'invio dell'header HTTP di autorizzazione Bearer:

Authorization: Bearer INSERISCI_QUI_IL_TUO_TOKEN

Endpoints

GET /health

Verifica lo stato di salute del servizio.

Risposta:

{
  "status": "ok"
}

POST /scrape Token

Scansiona una pagina indice (es. Diablo Immortal News) ed estrae le ultime N notizie.

Body (JSON):

Campo Tipo Default Descrizione
url String diabloimmortal.blizzard.com... URL della pagina news da scansionare.
max_articles Integer 1 Numero massimo di articoli da estrarre e processare. Valore accettato: 1–10.

Esempio richiesta:

{
  "max_articles": 3
}

Risposta (Array di oggetti):

[
  {
    "title": "Titolo Notizia",
    "url": "https://news.blizzard.com/...",
    "published_date": "10 giugno 2026",
    "content": "Testo estratto dell'articolo...",
    "thumbnail_url": "https://..."
  }
]

POST /scrape/article Token

Estrae i dati da un singolo URL specifico di un articolo.

Body (JSON):

Campo Tipo Obbligatorio Descrizione
url String Sì URL completo dell'articolo da scrapare.

Esempio richiesta:

{
  "url": "https://diabloimmortal.blizzard.com/en-us/news/article/..."
}

Risposta:

{
  "title": "Titolo Articolo",
  "url": "https://diabloimmortal.blizzard.com/en-us/news/article/...",
  "published_date": null,
  "content": "Testo estratto dell'articolo...",
  "thumbnail_url": "https://..."
}

Dettagli Tecnici

  • Smart Scraping: Il servizio non utilizza fragili selettori CSS/Regex. Converte la pagina in Markdown tramite MarkItDown di Microsoft e delega l'identificazione strutturale dei link all'LLM (OpenAI API compatibile).
  • Universalità dei Link: Include un motore di pre-processing che normalizza i Custom Web Components con attributi href (es. <blz-button>) in tag <a> standard e risolve gli URL relativi in assoluti prima della conversione.
  • Formato Data: Il campo published_date viene estratto dall'LLM durante lo scraping della pagina indice (/scrape). Per lo scraping di singoli articoli (/scrape/article) il campo è sempre null, non essendo disponibile nei metadati della pagina.
  • Limiti Contenuto: Il campo content è limitato a 8000 caratteri per evitare overflow nei prompt LLM di n8n.
  • Timeout: Il tempo massimo per ogni operazione di scraping è configurabile tramite la variabile d'ambiente SCRAPE_TIMEOUT (default: 300 secondi). Al superamento del timeout l'endpoint risponde con HTTP 504.
  • Rate limiting: Gli endpoint di scraping sono soggetti a un limite per IP configurabile tramite RATE_LIMIT (default: 20/minute). Al superamento del limite la risposta è HTTP 429. Il servizio riconosce gli header Cloudflare (CF-Connecting-IP) per identificare correttamente il client reale.
  • Validazione URL: I campi url accettano solo schemi http e https. URL che puntano a indirizzi IP privati, loopback o localhost vengono rifiutati con HTTP 422.
  • Tecnologia: Basato su Playwright (Chromium) per gestire contenuti caricati dinamicamente via JavaScript, integrato con l'auto-installazione del browser all'avvio.
